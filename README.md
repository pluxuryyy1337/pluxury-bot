# Бот PLUXURY для Telegram-канала

Делает посты-подборки с ценами lis-skins и посты по роликам. Каждое воскресенье в 12:00 сам присылает пачку контента.
Работает на GitHub Actions, компьютер включённым держать не нужно.

## Что в папке

| Файл | Что делает |
|---|---|
| `bot.py` | главный файл: принимает сообщения, оформляет посты |
| `prices.py` | цены с lis-skins и курс доллара |
| `youtube.py` | список роликов канала и их субтитры |
| `ai.py` | запросы к Claude |
| `style.py` | **стиль постов**: правь здесь, если хочешь писать по-другому |
| `state.json` | память бота: какие ролики уже использованы и т.п. (бот обновляет сам) |
| `.github/workflows/` | расписание запусков на GitHub |

## Как запустить (один раз)

1. **Создай репозиторий** на github.com: кнопка **New**, название `pluxury-bot`, тип **Public**.
2. **Загрузи файлы**: *Add file → Upload files* и перетащи туда всё содержимое папки `pluxury-bot`,
   включая папку `.github`. Файл `.env` не загружай, если он появится.
3. **Добавь секреты**: *Settings → Secrets and variables → Actions → New repository secret*:
   - `BOT_TOKEN`: токен бота от @BotFather
   - `ANTHROPIC_API_KEY`: ключ Claude (`sk-ant-...`)
4. **Узнай свой ID**: напиши своему боту `/start`, потом на GitHub открой *Actions → «Бот — ответы на сообщения» → Run workflow*.
   Бот ответит твоим Telegram ID. Добавь его секретом `OWNER_ID`.
5. Снова напиши боту `/start`. Он ответит подсказкой, и всё готово.

## Как пользоваться

- **Подборка**: картинка + подпись со списком скинов. Через 5–15 минут придёт готовый пост с картинкой.
- **Пост по ролику**: ссылка на ролик или текст сценария.
- **/week**: собрать недельную пачку прямо сейчас.
- Готовый пост пересылай в канал: *Переслать → убрать галочку «Показать отправителя»*.

## Если что-то не так

- **Цены в рублях немного отличаются от сайта.** lis-skins считает по своему курсу.
  Добавь секрет `RATE_MULTIPLIER`, например `1.05`: цены станут на 5% выше.
- **Бот не отвечает.** Открой вкладку *Actions*: красный крестик значит ошибку, внутри будет написано, какую.
- **Репозиторий приватный.** В `.github/workflows/messages.yml` поменяй `*/5` на `*/30`, иначе закончатся бесплатные минуты.
- **Поменять время воскресной пачки.** Строка `cron: "0 7 * * 0"` в `weekly.yml` (время UTC, у тебя +5 часов).
